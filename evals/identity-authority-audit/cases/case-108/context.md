# Context

A product manager asks about a "Generate report" feature during a
security questionnaire for a customer:

> When someone clicks "Generate report," it can take up to 20 minutes to
> finish and shows up later as a download link, sometimes after the
> person has logged out. The customer wants to know: if a user's access
> to a project got revoked five minutes after they clicked the button,
> would the report that finishes ten minutes later still include data
> from the project they can no longer see?

Files in this directory are the complete evidence available about this
system -- there is nothing else to consult.
