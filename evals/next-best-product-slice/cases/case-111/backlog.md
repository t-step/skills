# Backlog — Wayfare itineraries

1. **Let a travel agent view an itinerary's change history.** `docs/agent-guide.md`
   describes an agent being able to see exactly what changed on a client's
   itinerary, and when, as part of the product's intended experience.
   Today, an agent who wants to know what
   changed since yesterday has to compare a client's itinerary from
   memory — nothing in the product shows a history, even though it's now
   recorded correctly. 9 agents have asked about this directly in the
   agent-feedback form over the last two months. A minimal first step: a
   simple version list on the itinerary's existing detail page, reading
   from the already-verified version history, showing what changed and
   when for each entry.
